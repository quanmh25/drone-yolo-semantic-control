# Third-party scene assets

The following assets are bundled locally from [osrf/gazebo_models](https://github.com/osrf/gazebo_models). The upstream repository distributes them under [Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/); its license notice is preserved in [OSRF-LICENSE.txt](ros_ws/src/drone_scene/models/OSRF-LICENSE.txt).

| Local directory | Upstream source | Author recorded by upstream | Local changes |
| --- | --- | --- | --- |
| `ros_ws/src/drone_scene/models/person_standing` | [person_standing](https://github.com/osrf/gazebo_models/tree/master/person_standing) | Marina Kollmitz; created with MakeHuman | Set the model static for the stopping demonstration; omit unused original texture copies |
| `ros_ws/src/drone_scene/models/hatchback` | [hatchback](https://github.com/osrf/gazebo_models/tree/master/hatchback) | Nate Koenig | Resolve OBJ material texture paths relative to the mesh for offline Gazebo rendering; remove redundant `Tr` transparency declarations (the existing `d` opacity values are retained) |

Original `model.config` files retain author details. Downloaded files were verified against upstream Git blob SHA-1 values before local modifications. See [OSRF-UPSTREAM.json](ros_ws/src/drone_scene/models/OSRF-UPSTREAM.json) for the source file identifiers.

The existing `my_drone` asset identifies Olivier Crave / Parrot in its `model.config`. Its meshes predate this asset replacement and remain unchanged. The procedural tree and outdoor layout are generated by this project.
